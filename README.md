# Loan Approval Prediction App



A Machine Learning web application that predicts whether a loan application will be approved or rejected based on applicant details such as age, income, loan amount, credit score, and employment type.

The application includes data preprocessing (handling missing values), categorical feature encoding, train-test splitting, and model training using a Random Forest Classifier. It provides real-time predictions through an interactive Streamlit interface and simulates a practical financial risk assessment system.

---

## Key Features

* Real-time loan approval prediction
* Automated data preprocessing
* Categorical variable encoding
* Random Forest based classification model
* Interactive and user-friendly UI
* Deployable as a cloud-based web application
